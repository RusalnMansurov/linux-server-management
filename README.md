# Linux Server Management

Linux Server Management is a DevOps project for managing and monitoring
a Linux server using Bash scripts.

## Project Purpose

The purpose of this project is to practice Linux administration,
Git, GitHub, branching, code review, and team development.

## Project Structure

- `scripts/` - Linux administration scripts
- `docs/` - project documentation
- `README.md` - main project documentation
- `CONTRIBUTING.md` - contribution guidelines
